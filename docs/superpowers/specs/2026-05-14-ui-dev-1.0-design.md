# UI Dev 1.0 Design Spec

**Date:** 2026-05-14  
**Branch:** tuya_t5_pocket_buddy  
**Screen:** 384×168 monochrome (black/white)

---

## Overview

Add a `config_screen` between startup and main, add a `buddy_anim` animation utility, and apply terminal-style animations to existing screens.

---

## 1. Architecture

### New Files

| File | Purpose |
|---|---|
| `src/display/screens/config_screen.c/.h` | Config screen: IP input + WS connect |
| `src/display/widgets/buddy_anim.c/.h` | Shared animation utility: typewriter, number roll, blink |

### Modified Files

| File | Change |
|---|---|
| `src/display/screen_manager.c` | `screens_init()` pushes `config_screen` as first screen |
| `src/display/screens/startup_screen.c` | Timer callback targets `config_screen` instead of `main_screen` |
| `src/display/screens/main_screen.c` | Apply typewriter on header init |
| `src/display/screens/status_screen.c` | Apply typewriter row-by-row on init |
| `src/display/screens/chart_screen.c` | Bar height animation from 0 on init |
| `src/display/screens/approval_screen.c` | Selected option blink + `▶` prefix |

### Screen Flow

```
startup (1s timer)
  └→ config_screen
       ├─ ENTER → WS connect attempt
       │    ├─ success → screen_load(&buddy_main_screen)
       │    └─ fail    → toast_screen_show("连接失败", 3000), stay
       └─ ESC → no-op (config_screen is the base, no back)
```

## 2. config_screen Layout (384×168)

```
┌──────────────────────────────────────────────────────────────────────┐
│ WiFi [W]  claude buddy  [B]  85%              ← header 20px 黑底白字  │
├──────────────────────────────────────────────────────────────────────┤
│ Setup                                         ← 说明区 y=20..105      │
│                                                                      │
│  1. 打开涂鸦 App 扫码配网                                              │
│  2. 安装插件:                                                         │
│     claude mcp add buddy   ← 等宽字体反色块                            │
│  3. 在下方填写 PC 端服务器 IP                                           │
│  4. 按 ENTER 连接                                                     │
├── ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ──┤
│ Server IP:                                    ← 输入区 y=105..168     │
│                                                                      │
│  [1][9][2].[1][6][8].[0][0][1].[1]                                   │
│   ↑ cursor 反色高亮 + blink                                            │
│                                                                      │
│  ◄► 选位  ▲▼ 调值(0-9)  ENTER 确认                                    │
└──────────────────────────────────────────────────────────────────────┘
```

### IP Input Logic

- 12 digit cells, `cursor_pos` 0–11
- LEFT/RIGHT: move cursor (skip `.` separators conceptually)
- UP: digit +1 mod 10; DOWN: digit -1 mod 10 (wraps 9→0, 0→9)
- ENTER: assemble IP string → call `buddy_ws_connect(ip)` → on success `screen_load(&buddy_main_screen)`, on fail `toast_screen_show("连接失败", 3000)`
- KV storage: `tal_kv_set("buddy_server_ip", ip)` on success; `tal_kv_get` in `config_screen_init` to restore last IP
- Simulator guard: `#ifndef LVGL_PC_SIMULATOR` wraps KV + WS calls; simulator auto-jumps to main after 0ms

### Status Bar

- Header calls `buddy_status_bar_format()` same as other screens
- Shows WiFi, WS, battery — same widget pattern as `status_screen.c`

## 3. buddy_anim API

```c
// buddy_anim.h

/* Typewriter: reveal text character by character via lv_timer */
void buddy_anim_typewriter(lv_obj_t *label, const char *text, uint32_t interval_ms);

/* Number roll: animate label from integer `from` to `to`, step_ms per step */
void buddy_anim_roll_number(lv_obj_t *label, int from, int to, uint32_t step_ms);

/* Cursor blink: toggle bg/text color every period_ms using lv_timer */
void buddy_anim_blink(lv_obj_t *obj, lv_color_t color_a, lv_color_t color_b, uint32_t period_ms);
void buddy_anim_blink_stop(lv_obj_t *obj);
```

### Implementation Notes

- Typewriter: `lv_timer_create` callback appends one char per fire; stores state in a `malloc`'d context struct freed on completion or explicit cancel
- Blink: `lv_timer_create` toggles `LV_PART_MAIN` bg color and text color; `buddy_anim_blink_stop` calls `lv_timer_del`
- All timers must be cancelled in the owning screen's `deinit()` to prevent use-after-free

## 4. Animation Application per Screen

| Screen | Animation |
|---|---|
| `config_screen` | "Setup" title typewriter on init; cursor cell blink |
| `approval_screen` | Current option `▶` prefix + blink on selection change |
| `main_screen` | "claude buddy" header typewriter on first init |
| `status_screen` | Stat rows typewriter row-by-row (20ms/char) |
| `chart_screen` | Bar height `lv_anim_t` grow from 0→target (200ms, ease-out) |
| `pie_screen` | No change (LVGL arc already animates) |

## 5. Simulator / Hardware Isolation

```c
// config_screen.c — connect button handler
#ifdef LVGL_PC_SIMULATOR
    // skip KV write and WS connect, go directly to main
    screen_load(&buddy_main_screen);
#else
    tal_kv_set("buddy_server_ip", ip_str);
    if (buddy_ws_connect(ip_str) == 0) {
        screen_load(&buddy_main_screen);
    } else {
        toast_screen_show("连接失败", 3000);
    }
#endif
```

## 6. Out of Scope

- Port configuration (only IP; port is hardcoded or from existing config)
- WiFi provisioning UI (mentioned in spec as text only, not interactive)
- pie_screen animation (LVGL arc native animation sufficient)
