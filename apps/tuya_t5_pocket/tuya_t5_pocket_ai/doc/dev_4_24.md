# 开发3.0

本次开发主要面向UI 设计和插件设计两部分内容。

蓝牙通信协议需要兼容：apps\tuya_t5_pocket\claude-desktop-buddy\REFERENCE.md



## UI 开发

1、主页面设计（第二个屏幕）

- 顶部状态栏，左上角显示 claude buddy 字样，中间显示时间，右边显示 wifi，蓝牙连接情况和电量百分比。
- 左边区域保持当前设计，显示宠物角色和宠物名字，等级。
- 右边区域根据 project 字段进行划分，每个Project 下面显示存在的会话（会话名称（不超过限制）＋会话ID(会话id 只显示前8个字符)），如果当前会话正在执行就在会话尾部加一个黑点闪烁，如果会话任务结束黑点消失。这部分做成一个滚动，可以通过摇杆上下移动选择进入会话，查看会话的日志和会话信息。
- 主页面最下面再加一条几像素高的黑线，分成四部分，可以通过摇杆左右移动切换页面，切换那个页面就高亮（反色或者变大）下面的黑条。
- 主屏幕作为第二个屏幕

2、会话页面设计

- 顶部状态栏和主页面一致不改变
- 进入会话页面之后，左边显示会话名称，会话id，会话上下文、模型、token使用量等和会话相关的信息。左边显示区域偏小。
- 右边显示会话的日志，包括工具调用情况，回复情况，根据现有的log完善，但只显示当前会话的内容。

3、status 页面设计（第一个屏幕）

- 顶部状态栏和主页面一致不改变
- 从主页面摇杆左键切换到status页面，通过列表显示 claude 的各项信息，claude 版本，今天 token 使用量，花费金额等等你觉得必要的信息。

4、曲线图页面设计（第三个屏幕）

- 顶部状态栏和主页面一致不改变
- 从主页面摇杆右键进入曲线图页面，汇总过去7天，14天，28天的token使用量曲线图，横坐标是日期，纵坐标是token使用量单位（根据token存在的最大值对纵坐标进行归一化处理，最小是0，最大根据历史记录）
- 通过摇杆上下移动可以切换三个时间段的曲线图。

5、饼状图展示（第四个屏幕）

- 顶部状态栏和主页面一致不改变
- 从曲线图右键进入饼状图界面，展示所有的模型token使用占比情况。



## 插件开发

**根据上面的 UI 开发从  .claude/ 路径下获取对应的数据通过蓝牙发送到设备并且保持协议兼容。**
