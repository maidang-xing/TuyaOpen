## Subproject A — ASR over BLE → Claude 后台

### Feasibility Analysis

**链路可行性：成立**。论据：

1. **设备侧出口已就绪**：`buddy_ble.c::__send_raw()` 已实现 MTU 自适应分片 + 换行分隔 + 互斥保护，新增一个 sender 函数即可，零协议风险。
2. **ASR 数据来源已定位**：`game_ai_chat.c:33` 的 `AI_USER_EVT_ASR_OK` 分支 `event->data` 是 `AI_NOTIFY_TEXT_T*`（`{datalen, data}`），是 UTF-8 字符串。当前未消费，加 hook 不影响其他逻辑。
3. **会话 ID 来源**：`buddy_main_screen.c::s_sel_flat` 索引 + `s_state.sessions[].sid`（11 字符短 id）。只读取，不影响主屏渲染。
4. **后台已有 BLE 客户端**：`apps/tuya_t5_pocket/claude-cli-plugin/daemon/tuya_pocket_buddy/wire.py::parse_frame` 是设备→host 帧的入口；新增一个 `("asr", payload)` kind 即可。
5. **单向**：用户确认设备→后台单向，省去 ack/重试，降低复杂度。

**风险与对策：**

| 风险 | 影响 | 对策 |
|---|---|---|
| ASR 文本含非 ASCII 引号、反斜杠、控制字符 | JSON 注入 / 解析失败 | 用 `cJSON` 构造而非手拼字符串 |
| BLE 未连接时调用 `__send_raw` | 无 host 时丢帧 | `__send_raw` 已返回 `OPRT_COM_ERROR`；调用方仅记录 PR_DEBUG |
| 选中会话索引在 BLE 任务中并发读取 | 数据竞争 | 暴露 `buddy_main_screen_get_selected_sid()`，内部加 `lv_vendor_disp_lock()` |
| ASR 事件可能在 LVGL 任务中被回调，调用 BLE 反向锁顺序 | 死锁 | sender 内部仅持 `s_state_mutex`，不持 LVGL 锁 |
| 长 ASR 文本（>1KB） | 单帧超 BLE_RX_BUF_CAP（host 侧 8KB OK） | 单帧 cJSON 自然紧凑，限制 ≤ 1024 字节；超过则截断 |

**Wire Protocol 新帧（device → host）：**
```json
{"asr":"<utf-8 text>","sid":"<11 chars>"}\n
```
- 设备侧编码器：`buddy_ble_send_asr(const char *text, const char *sid)`
- 后台侧：`wire.py::parse_frame` 在 `"ack"` 检查后增加 `if "asr" in decoded: return ("asr", decoded)`
- 路由：`hook_router.py` 收到 `kind="asr"` 时，根据 `payload["sid"]` 找到对应运行中 Claude CLI 会话的 stdin 写入文本 + `\n`

```c
OPERATE_RET buddy_main_screen_get_selected_sid(char *out_sid, size_t out_len)
{
    if (out_sid == NULL || out_len < 12U) {
        return OPRT_INVALID_PARM;
    }
    out_sid[0] = '\0';
    OPERATE_RET rt = OPRT_NOT_FOUND;
    lv_vendor_disp_lock();
    if (s_flat_count > 0 && s_sel_flat < s_flat_count &&
        !s_flat[s_sel_flat].is_header) {
        uint8_t si = s_flat[s_sel_flat].sess_idx;
        if (si < s_state.sessions_count) {
            (VOID_T)snprintf(out_sid, out_len, "%s", s_state.sessions[si].sid);
            if (out_sid[0] != '\0') {
                rt = OPRT_OK;
            }
        }
    }
    lv_vendor_disp_unlock();
    return rt;
}
```

```c
/**
 * @brief Send a single ASR transcript line to the desktop host.
 * @param[in] text  UTF-8 ASR text (must not contain NUL); truncated to 1024 B
 * @param[in] sid   short session id (11 chars + NUL) or empty string
 * @return OPRT_OK on success
 */
OPERATE_RET buddy_ble_send_asr(const char *text, const char *sid)
{
    if (text == NULL || text[0] == '\0') {
        return OPRT_INVALID_PARM;
    }
    if (s_conn_handle == TKL_BLE_GATT_INVALID_HANDLE) {
        return OPRT_COM_ERROR;
    }

    cJSON *root = cJSON_CreateObject();
    if (root == NULL) {
        return OPRT_MALLOC_FAILED;
    }

    /* Bound input length defensively before handing to cJSON. */
    char clipped[1024 + 1];
    size_t n = strnlen(text, sizeof(clipped) - 1U);
    memcpy(clipped, text, n);
    clipped[n] = '\0';

    cJSON_AddStringToObject(root, "asr", clipped);
    cJSON_AddStringToObject(root, "sid", (sid != NULL) ? sid : "");

    char *out = cJSON_PrintUnformatted(root);
    OPERATE_RET rt = OPRT_COM_ERROR;
    if (out != NULL) {
        size_t out_len = strlen(out);
        char *buf = (char *)tal_malloc(out_len + 2U);
        if (buf != NULL) {
            memcpy(buf, out, out_len);
            buf[out_len] = '\n';
            buf[out_len + 1U] = '\0';
            rt = __send_raw(buf, (uint16_t)(out_len + 1U));
            tal_free(buf);
        } else {
            rt = OPRT_MALLOC_FAILED;
        }
        cJSON_free(out);
    }
    cJSON_Delete(root);
    return rt;
}
```
